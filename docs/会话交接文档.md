## 一、项目概述

**项目名称**：飞书银行短信自动记账系统
**技术栈**：Spring Boot 3.2.10 + JDK 17 + MyBatis-Plus 3.5.6 + MySQL 8.0 + RabbitMQ + Redis + 飞书开放平台 API + 通义千问 AI
**部署环境**：VMware 虚拟机 Ubuntu 22.04，IP `10.13.27.249`

### 核心功能
1. 手机 SmsForwarder 抓取银行短信 → 转发到后端
2. 后端解析短信 → 发飞书群消息 + 写飞书多维表格 + 存 MySQL
3. RabbitMQ 异步处理 + 重试 + 死信队列
4. AI 大模型（通义千问）语义解析 + 自然语言指令（删除/更新记录）
5. 仪表盘统计（折线图/饼图/柱状图，支持周/月对比）
6. 多用户支持（JWT + Redis token + 数据隔离）
7. 日记与日迹模块（最新功能，见 git log 最新 commit）

## 五、鉴权体系（核心，详见学习文档）

### 5.1 认证流程
```
登录 /api/login → BCrypt 校验 → 生成 JWT → 写 Redis (auth:token:<jwt> → userId, TTL 7天)
请求 → AuthInterceptor → 解析 JWT → 查 Redis → UserContext.setUserId → 放行
登出 /api/logout → 删 Redis key → token 立即失效
```

### 5.2 关键设计
- **JWT + Redis 结合**：JWT 防篡改、Redis 控失效
- **RedisSafeTemplate**：`@Autowired(required=false)` + try/catch 兜底，Redis 挂了应用也能启动（降级为纯 JWT）
- **UserContext（ThreadLocal）**：`afterCompletion` 里必须 `clear()`，防线程池串号
- **两套鉴权**：浏览器用 JWT（Authorization 头），SmsForwarder 用 sms_key（URL `?token=xxx`）

### 5.3 拦截器白名单
`/api/login`、`/api/ping`、`/api/sms`、`/api/register`、`/api/reset-admin-password`

### 5.4 管理员账号
- **用户名**：`admin`
- **密码**：`admin123`
- **sms_key**：`my-sms-key-001`
- **重置密码接口**：`GET /api/reset-admin-password?raw=admin123`（运行时用 BCrypt 现场编码写库，避免手写 SQL 哈希被特殊字符破坏）
